# AI QA Copilot

## Overview

AI QA Copilot is an AI-powered web application that helps QA engineers generate intelligent software test cases from user requirements using Generative AI.

## Features

- Generate Positive Test Cases
- Generate Negative Test Cases
- Generate Boundary Test Cases
- Generate Edge Test Cases

## Tech Stack

- Python
- Streamlit
- OpenAI API
- Git
- GitHub
